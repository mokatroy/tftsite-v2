# قالب تحديث الباتش — MokaTroy TFT

الهدف: تحديث الموقع مع كل باتش **من غير ما تبوظ الصفحات**.

قاعدة ذهبية: **لمّس ملفات الداتا فقط** إلا لو السيت اتغيّر أو حاجة اتكسرت.

---

## 1) حدد نوع الباتش

| النوع | مثال | إيه هتعدّل |
|------|------|------------|
| **صغير** | 18.3 → 18.3b / أرقام نيرف وباف | `data/patches.json` بس |
| **متوسط** | 18.3 → 18.4 ميتا اتغيّر | patches + كومبات + (اختياري) BiS / أوجمنتس |
| **كبير** | سيت جديد (Set 19) | داتا + صور + تريتس + مراجعة UI |

---

## 2) الملفات المسموح تعديلها

### دائمًا (أي باتش)
```
data/patches.json
```

### باتش متوسط (ميتا / كومبات)
```
data/v2_comps.json          ← لو مستخدم
data/v2_comps_extra.json
data/v2_comps_extra2.json
data/v2_comps_extra3.json
```

### أحيانًا فقط (لو حاجة غلط أو ميتا قلبت)
```
js/comp-detail.js     ← COMP_AUGMENTS فقط (متلمسش render)
js/ui-core.js         ← CHAMP_BIS فقط (متلمسش renderBoard)
```

### ممنوع تلمسه في تحديث باتش عادي
```
index.html, comps.html, builder.html, css/*, locale.js, tooltip.js, board.css
```
إلا لو في باج واضح ومش متعلق بالباتش.

---

## 3) خطوات الباتش الصغير (10 دقايق)

1. افتح ملاحظات الباتش الرسمية (TFT / Riot) أو TFT Academy.
2. افتح `data/patches.json`.
3. أضف أو حدّث الإدخال الأعلى (أحدث باتش):

```json
{
  "version": "18.4",
  "title": { "ar": "باتش 18.4", "en": "Patch 18.4", "ja": "パッチ 18.4" },
  "summary": {
    "ar": "جملة أو اثنين عن أهم التغييرات",
    "en": "One or two sentences on the key changes",
    "ja": "主な変更の要約"
  },
  "changes": [
    {
      "name": "ChampionOrSystem",
      "type": "buff",
      "text": { "ar": "...", "en": "...", "ja": "..." }
    },
    {
      "name": "Another",
      "type": "nerf",
      "text": { "ar": "...", "en": "..." }
    }
  ]
}
```

- `type` المسموح: `buff` | `nerf` | `change` | `system`
4. احفظ → Commit على `main` برسالة زي: `patch: 18.4 notes`
5. افتح `/patch.html` وعمل **Ctrl+Shift+R** وتأكد إن الملاحظات ظهرت.

**خلاص. الباتش الصغير انتهى.**

---

## 4) خطوات الباتش المتوسط (ميتا)

بعد ما تخلّص `patches.json`:

### أ) تحديث الكومبات
لكل كومب لسه meta (من Academy / إحصائيات):

| حقل | معناه |
|-----|--------|
| `tier` | S / A / B / C |
| `style` | فاست 8، سلو رول 7–8، ريرول 6… |
| `units` | تشكيلة الفاينل |
| `earlyUnits` | وحدات البدري |
| `stages` | 2–3 جمل قصيرة Early/Mid/Late |
| `guide` | نصيحة سريعة (جملة أو اتنين) |
| `items` | أيتمز مشتركة / ملاحظات |
| `traits` | التريتس الأساسية |

**متكتبش كلام طويل** — اللاعب بيتوه.

مثال `stages`:
```json
"stages": [
  { "stage": 2, "text": { "ar": "ون ستريك بوحدات رخيصة.", "en": "Win-streak with cheap units." } },
  { "stage": 3, "text": { "ar": "لفّ لفل 8 ورول للكاري.", "en": "Hit 8 and roll for carries." } },
  { "stage": 4, "text": { "ar": "ثبّت 2★ والكابستون.", "en": "Stabilize 2★ and capstone." } }
]
```

### ب) أوجمنتس (لو ترتيب المقترح اتغيّر)
في `js/comp-detail.js` عدّل **كائن `COMP_AUGMENTS` فقط**:
```js
"slug-بتاع-الكومب": [
  { "name": "Built Different", "rarity": "Gold" },
  { "name": "Component Grab Bag", "rarity": "Silver" }
]
```
الأولوية (أيتمز/اقتصاد/كومبات) بتتحدد تلقائي من اسم الأوجمنت — مش محتاج تضيفها يدوي إلا لو حابب.

### ج) BiS (لو الكاري اتغيّر)
في `js/ui-core.js` عدّل **`CHAMP_BIS` فقط**:
```js
"champname": ["Item One", "Item Two", "Item Three"],
```
أسماء الأيتمز لازم تطابق اللي الموقع بيعرفها (نفس أسماء Community Dragon / اللي مستخدمة في الموقع).

### د) بعد التعديل
1. Commit منفصل لكل نوع لو حابب:
   - `patch: 18.4 notes`
   - `meta: update comps for 18.4`
   - `meta: refresh BiS / augments`
2. راجع **صفحة كومب واحدة** على الأقل:
   - البورد ظاهر
   - طريقة اللعب
   - الاقتصاد واللفلنج
   - الأوجمنتس بالصور
3. راجع `/comps.html` إن الشبكة مش فاضية.
4. **متعملش** تعديل على CSS أو nav في نفس اليوم إلا للضرورة.

---

## 5) باتش كبير (سيت جديد) — checklist

- [ ] وحدات جديدة → صور `champImg` / mapping في `ui-core` أو `champions.js`
- [ ] تريتس جديدة → بيانات التريتس + أيقونات
- [ ] أيتمز جديدة/مالغية → فرن الأيتمز + BiS
- [ ] أوجمنتس جديدة → `AUG_PRIO` + أيقونات لو ناقصة
- [ ] كل الكومبات من الصفر أو إعادة كتابة الميتا
- [ ] Builder pool (قائمة التشامبيونز)
- [ ] اختبار موبايل + ديسكتوب

السيت الجديد = جلسة شغل كبيرة؛ الباتش العادي لأ.

---

## 6) مصادر تعتمد عليها

1. **TFT Academy** — بورد، BiS، playstyle، أوجمنتس
2. **Riot patch notes** — نص الباتش الرسمي
3. **Community Dragon** — صور (عادةً مش محتاج تغيّر روابط)

---

## 7) لو حاجة باظت بعد التحديث

| العرض | السبب الشائع | الحل |
|------|----------------|------|
| صفحة التشكيلات فاضية | JSON فاضي أو syntax error | رجّع آخر commit شغال على ملفات `data/v2_comps*` |
| كومب فاضي | `slug` مش متطابق | تأكد `comp.html?slug=...` = `slug` في JSON |
| صور أيتمز/أوجمنتس مكسورة | اسم غلط | انسخ الاسم من كومب شغال |
| الموقع قديم رغم التعديل | كاش Cloudflare / المتصفح | غيّر `?v=` في السكربت أو Ctrl+Shift+R |

**مهم:** لو هترجع نسخة قديمة، ارجع **ملف الداتا** فقط — متستبدلش `comp-detail.js` كامل من غير داعي.

## 9) Checklist سريع قبل ما تقفل

- [ ] `patches.json` فيه رقم الباتش الجديد
- [ ] `/patch.html` يعرض التغييرات
- [ ] `/comps.html` فيه كومبات
- [ ] كومب واحد على الأقل: بورد + شرح + اقتصاد + أوجمنتس
- [ ] مفيش تعديل عشوائي على HTML/CSS الصفحات التانية
- [ ] Hard refresh اتعمل

---

## 10) إمتى تحتاج مساعدة (الشات)

- سيت جديد / وحدات جديدة كتير
- البورد أو الـ UI اتكسر ومش عارف ترجع الداتا
- عايز تضيف فيتشر جديدة (مش مجرد أرقام باتش)

**باتش عادي (نيرف/باف + ترتيب ميتا) = أنت تقدر لوحدك بالقالب ده.**
